# Trend Pullback Strategy

## 摘要
這份文件定義 `TDHighLow` 的順勢交易系統 `V1`，作為後續 strategy 實作的規格來源。

核心原則：
- 只做大週期順勢單
- 用中週期找回撤區
- 用小週期確認回撤是否停下來
- 再用更小週期或價格行為找真正進場點
- 不追價，只做回撤後再啟動

## 週期分工
- `4H`：主方向
- `1H`：中繼方向與 Fib 基準
- `15m`：是否回撤到位
- `5m`：是否停下來、是否準備再啟動

## 狀態代號
- `L` = `Long` = 多頭延續
- `S` = `Short` = 空頭延續
- `ML` = `Mixed from Long weakening` = 混合(由多頭轉弱)
- `MS` = `Mixed from Short strengthening` = 混合(由空頭轉強)
- `M` = `Mixed` = 混合

硬規則：
- Never interpret `L` as `Low`
- Never interpret `S` as sell-only sentiment
- `L / S` are structure-direction codes, not price-level abbreviations

## 一、方向條件
做多只看：
- `4H = L`
- `1H = L`

做空只看：
- `4H = S`
- `1H = S`

如果 `4H` 與 `1H` 不一致：
- 不做順勢單

## 二、位置條件
做多：
- `15m` 價格回撤進入 `1H` 的 `0.5 ~ 0.618` 區間
- 最好同時接近 `1H` 最近有效 `low / HL`

做空：
- `15m` 價格反彈進入 `1H` 的 `0.5 ~ 0.618` 區間
- 最好同時接近 `1H` 最近有效 `high / LH`

如果沒進區間：
- 不進場
- 只觀察

## 三、停下來條件
做多時，`5m` 要出現：
- `MS`

定義：
- 回撤中的小空頭開始轉強
- 代表空方力量耗盡
- 可開始觀察右側確認

做空時，`5m` 要出現：
- `ML`

定義：
- 反彈中的小多頭開始轉弱
- 代表多方力量耗盡
- 可開始觀察右側確認

## 四、再啟動條件
做多時，至少滿足其一：
- `5m = L`
- `5m` 結構出現 `HH / HL`
- 假跌破收回
- 二測不破
- 背離後止跌
- 持續增量
- `15m` 合適 `OB`

做空時對稱：
- `5m = S`
- `5m` 結構出現 `LH / LL`
- 假突破收回
- 二測不過
- 背離後止漲
- 持續增量轉弱
- `15m` 合適 `OB`

## 五、進場定義
做多進場成立：
- `4H = L`
- `1H = L`
- `15m` 進入 `1H 0.5 ~ 0.618`
- `5m = MS`
- 且 `5m` 出現再啟動訊號

做空進場成立：
- `4H = S`
- `1H = S`
- `15m` 進入 `1H 0.5 ~ 0.618` 反彈區
- `5m = ML`
- 且 `5m` 出現再啟動訊號

## 六、止損規則
積極版：
- 放 `5m` 最近 `swing` 外

保守版：
- 放 `15m` 最近 `swing` 外

做多：
- 放最近有效 `low` 下方

做空：
- 放最近有效 `high` 上方

如果停損過大：
- 放棄
- 或降倉位

## 七、出場規則
第一目標：
- 前高 / 前低

第二目標：
- `1.382`
- `1.618`

可分批：
- 第一段先減碼
- 第二段看延續

## 八、不做條件
- `4H` 與 `1H` 不一致
- `15m` 沒進 `1H 0.5 ~ 0.618`
- 做多時 `5m` 仍明確 `S`
- 做空時 `5m` 仍明確 `L`
- 只有停下來，沒有再啟動
- 已經離回撤區太遠才想追

## 九、執行流程
1. `4H / 1H` 看方向是否一致
2. `15m` 看是否進入 `1H 0.5 ~ 0.618`
3. `5m` 看是否先停下來：`MS / ML`
4. 再等 `5m` 再啟動
5. 進場
6. 止損放 `swing` 外

## 十、一句話版本
- 大週期順勢
- 中週期進回撤區
- 小週期先停，再啟動
- 只做回撤，不追價
