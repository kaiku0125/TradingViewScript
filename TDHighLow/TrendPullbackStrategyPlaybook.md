# Trend Pullback Strategy Playbook（做多）

## 摘要
本文件僅定義**順勢做多、回撤進場**之交易規格（`V1`），作為後續 strategy 實作與覆盤之依據。

核心原則：
- 只在大週期**多頭結構**下找機會
- 用中週期（`中(P)`）界定回撤區（Fib）
- 用微週期（`微(P)`）確認回撤區內是否出現 **RSI 背離再啟動**
- 不追價，只做**回撤後再啟動**

## 週期架構（做多）
本文件使用**相對週期**概念，不把最大週期寫死為 `4H`。

支援時框：
- 月
- 週
- 日
- `4H`
- `1H`
- `15m`
- `5m`

使用方式：
- 使用者先選擇最大分析週期 `大(P)`
- 系統再依固定順序自動推定 `中(P)`、`小(P)`、`微(P)`
- 因策略至少需要四層週期，所以 `大(P)` 最小只能選到 `4H`

允許使用者選擇的 `大(P)`：
- 月
- 週
- 日
- `4H`

對應關係：
- 若 `大(P) = 月`，則 `中(P) = 週`，`小(P) = 日`，`微(P) = 4H`
- 若 `大(P) = 週`，則 `中(P) = 日`，`小(P) = 4H`，`微(P) = 1H`
- 若 `大(P) = 日`，則 `中(P) = 4H`，`小(P) = 1H`，`微(P) = 15m`
- 若 `大(P) = 4H`，則 `中(P) = 1H`，`小(P) = 15m`，`微(P) = 5m`

策略與後續 strategy 實作皆應以 `大(P) / 中(P) / 小(P) / 微(P)` 為主，不應把 `4H / 1H / 15m / 5m` 視為固定唯一組合。

## 週期分工（做多）
- `大(P)`：主方向須為多頭延續
- `中(P)`：中繼方向須一致，並作為 Fib 基準（回撤區）
- `小(P)`：價格是否**回撤進區**
- `微(P)`：是否在回撤區內出現 **RSI 背離再啟動**

## 狀態代號（做多會用到的讀法）
- `L / S / M / ML / MS` 的語意參照 [MarketStateAgent.md](/Users/kevinlin/MyProject/TradingViewScript/TDHighLow/MarketStateAgent.md) 與 `TDHighLowIndicator` 目前的結構判斷邏輯
- `L` = `Long` = 多頭延續（結構方向代號，**不是**價位 Low）
- `ML` = `Mixed from Long weakening` = 混合（由多頭轉弱）
- `MS` = `Mixed from Short strengthening` = 混合（由空頭轉強）— 在**做多回撤**脈絡下，用於「空方力道衰竭、可先等右側」之訊號
- `M` = `Mixed` = 混合
- 若需辨識反向結構：見到 `S`（空頭延續）代表與做多方向不一致，應**不做多**（本文件不展開做空規格）

硬規則：
- Never interpret `L` as `Low`

## 一、方向條件（做多）
同時滿足：
- `大(P) = L`
- `中(P) = L`

若 `大(P)` 與 `中(P)` **不一致**：
- **不做此套做多順勢單**（僅觀察）

## 二、位置條件（做多）
- `小(P)` 價格**回撤**進入以 `中(P)` 最近有效擺幅所推導之 **`0.5 / 0.618 / 0.66`** 區間
- 最好同時接近 `中(P)` 最近有效 **`low` / `HL`**

若**未進**上述回撤區間：
- 不進場
- 只觀察

## 三、再啟動條件（做多）
在已滿足「方向 + 進區」之前提下，`微(P)` 的再啟動條件固定為：
- **RSI bullish divergence**

定義（策略 V1）：
- 背離必須發生在價格已位於 `中(P)` 的 **`0.5 / 0.618 / 0.66`** 回撤區內時才有效
- 僅接受 **regular bullish divergence**
- 價格在 `微(P)` 形成更低低點，但 RSI 對應 pivot 形成更高低點
- 背離需於 `微(P)` 收線確認後才算成立

## 四、reset 條件（做多）
本策略採上層優先邏輯：
- 先看 `大(P)`
- 再看 `中(P)`
- 再看 `小(P)` 是否進區
- 最後才看 `微(P)` 是否出現背離

硬規則：
- 若 `中(P)` 狀態不再是 `L`，本輪 setup **立即 reset**
- 即使 `小(P)` 已在等待回撤，或 `微(P)` 已接近再啟動，也都**不再等待**
- 只有當 `中(P)` 重新回到 `L`，才可重新建立新一輪做多 setup

## 五、進場定義（做多）
**進場成立**須同時滿足：
- `大(P) = L`
- `中(P) = L`
- `小(P)` 已進入 `中(P)` 的 **`0.5 / 0.618 / 0.66`** 回撤區
- `微(P)` 已在回撤區內出現 **RSI bullish divergence**
- 背離於 `微(P)` 收線確認
- 進場以背離確認當根收線為準

## 六、結構失效（做多）
本節用來定義：什麼情況下，本輪順勢做多 setup 不再只是回撤，而應視為失效。

有效低點定義：
- 指本輪 setup 在 `中(P)` 上用來界定回撤區與 Fib 基準的**已確認有效低點**
- 實務上以本輪劇本所鎖定的最近一次 **`HL`** 或等價 **`swing low`** 為準
- 若策略實作時存在多個候選低點，應以**本輪 setup 已鎖定之同一錨點**為準，不得在 setup 進行中任意更換

失效判斷（硬規則）：
- 若 `中(P)` 當根 K 線 **close 跌破**本輪 setup 鎖定的有效低點，則該輪做多 setup **立即失效**
- 不以單純 `wick` 刺破作為唯一失效依據
- setup 一旦失效，即**不再等待** 背離、再啟動或進場訊號
- 若之後要重新做多，必須重新滿足方向、進區與後續確認條件

對應說明：
- 在常見對應 `大(P) = 4H`、`中(P) = 1H` 時，本條即為口語中的「`1H` close 跌破有效低點，做多 setup 失效」

## 七、止損與倉位規則（做多）
止損固定：
- 放在本輪 setup 所鎖定的 `中(P)` **有效低點**下方

倉位固定採美元風險模型：
- 範例資金：`1000` 美金
- 每筆固定最大虧損：`20` 美金
- 以 `進場價 - 停損價` 的價差，反推可承受的部位大小
- 計算概念：`qty = risk_dollar / abs(entry - stop)`

原則：
- 若 `entry <= stop`
- 或停損距離為 `0`
- 或反推出來的 `qty <= 0`
- 則該筆交易直接跳過

## 八、出場規則（做多）
第一目標：
- `50%` 部位在 `中(P)` **有效高點**出場

第二目標（延伸）：
- 剩餘 `50%` 部位以 `中(P)` 的 **`1.382` 與 `1.618` 延伸目標平均值**出場
- 即：`((1.382 extension + 1.618 extension) / 2)`

停損：
- 兩段出場共用同一個 `中(P)` 有效低點停損

## 九、不做條件（做多）
- `大(P)` 與 `中(P)` 方向不一致（無法視為多頭順勢）
- `中(P)` 狀態已離開 `L`
- `小(P)` 未進 `中(P)` 的 `0.5 / 0.618 / 0.66` 回撤區
- 已觸發 `中(P)` 結構失效（見第六節）
- `微(P)` 未在回撤區內出現有效 RSI bullish divergence
- 價格已離回撤區過遠才追價

## 十、執行流程（做多）
1. `大(P) / 中(P)` 是否皆為 `L`
2. 先鎖定本輪 `中(P)` 的有效低點與有效高點
3. `小(P)` 是否進入 `中(P)` 的 `0.5 / 0.618 / 0.66`
4. 若 `中(P)` 狀態離開 `L`，立即 reset，回到第 1 步
5. 確認本輪 setup 尚未觸發 `中(P)` 收盤跌破有效低點之結構失效
6. 再等 `微(P)` 在回撤區內出現 RSI bullish divergence
7. 於背離確認收線進場
8. 停損放在 `中(P)` 有效低點下方
9. `50%` 在 `中(P)` 有效高點出場
10. 剩餘 `50%` 在 `((1.382 + 1.618) / 2)` 延伸均值出場

## 十一、一句話版本（做多）
- 大週期順勢多
- 中週期進回撤區
- 中(P) 一變，整輪 reset 重來
- 微週期只等回撤區內 RSI 背離
- 只做回撤，不追價
