# TD High Low Trading Playbook

## 摘要
這套系統以 `TDHighLowIndicator` 為核心，結合：
- 結構方向
- ZigZag 高低點
- Fib 回撤區
- TD 序列 timing

核心原則只有一句：

只做順大方向的回撤，再等小週期重新啟動，不追突破。

## 名詞定義
`大(P)`：
決定主方向的週期，只用來回答「主做多、主做空，還是先不做」。

`中(P)`：
找回撤區與結構完整度的週期，只用來回答「這個位置值不值得等」。

`小(P)`：
找進場時機的週期，只用來回答「現在能不能進」。

`swing`：
指標已確認的最近有效結構高低點，不是任意一根 K 棒的高低。

## 三週期框架
1. `大(P)` 定方向，只順勢做。
2. `中(P)` 找回撤區與結構是否完整。
3. `小(P)` 等重新轉強或轉弱後才進場。

常見組合範例：
- `1D -> 4H -> 1H`
- `4H -> 1H -> 15m`
- `1W -> 1D -> 4H`

## 大(P) 要看什麼
只看結構方向：
- `多頭延續`：主做多
- `空頭延續`：主做空
- `混合`：保守、降倉位，或直接不做
- `未定`：不做

結論：
- 大週期多頭，不代表立刻進場，只代表後續只找多單
- 大週期空頭，不代表立刻進場，只代表後續只找空單

## 中(P) 要看什麼
中週期的任務是找位置，不是找衝動進場點。

主要觀察：
- 是否回到 `0.5 / 0.618 / 0.66`
- 是否靠近最近一組有效 `H/L`
- 回撤時，中週期結構是否仍完整

多單時：
- 觀察是否回到回撤區
- 最近 low 沒有被破壞

空單時：
- 觀察是否反彈到回撤區
- 最近 high 沒有被突破

如果中週期位置不好：
- 不做
- 即使小週期有 TD 訊號也不做

## 小(P) 要看什麼
小週期最先出現變化，但它只用來等確認。

重點觀察：
- `TD 7 / 8 / 9 / 11 / 12 / 13`
- `HH / HL` 或 `LH / LL`
- 止跌 / 止漲
- 重新啟動，而不是單純波動

關鍵觀念：
- `小(P) 混合 = 先等`
- 小週期混合，不代表立刻反轉
- 小週期混合，通常代表回撤還沒結束，或正在整理

只有當小週期重新順大方向時，才是更好的進場訊號：
- 多單：重新出現 `HH / HL`
- 空單：重新出現 `LH / LL`

## 多單規則
需同時滿足：
1. `大(P)` 為 `多頭延續`
2. `中(P)` 回到 `0.5 / 0.618 / 0.66`
3. `中(P)` 結構未破
4. `小(P)` 由混合或回撤狀態重新轉強
5. `小(P)` 出現可用的 TD timing

進場原則：
- 只做回撤後的再啟動
- 不追突破

## 空單規則
需同時滿足：
1. `大(P)` 為 `空頭延續`
2. `中(P)` 反彈到 `0.5 / 0.618 / 0.66`
3. `中(P)` 結構未破
4. `小(P)` 由混合或反彈狀態重新轉弱
5. `小(P)` 出現可用的 TD timing

進場原則：
- 只做反彈後的再轉弱
- 不追破底

## 止損規則
積極版：
- 止損放 `小(P)` 近期 swing 外

保守版：
- 止損放 `中(P)` 近期 swing 外

多單：
- 放最近有效 low 下方

空單：
- 放最近有效 high 上方

如果停損距離太大：
- 不做
- 或降倉位

## 出場規則
第一目標：
- 前高 / 前低

第二目標：
- `1.382`
- `1.618`

實務上可分批：
- 第一段先減碼
- 第二段讓趨勢延伸

## 不做的情況
- `大(P)` 為 `混合`
- `大(P)` 為 `未定`
- `中(P)` 不在合理回撤區
- `中(P)` 結構已破
- `小(P)` 仍然混合
- 小週期只有 TD 數字，沒有結構重新啟動

## 系統摘要
𖤐  `大(P)` 定方向，只順勢  
𖤐  `中(P)` 找回撤與結構  
𖤐  `小(P)` 等再啟動  
𖤐  `小(P)` 混合＝先等  
𖤐  `HH / HL` 或 `LH / LL` 才進  
𖤐  止損放 swing 外  
𖤐  只做回撤，不追價
